OBATKU — Ringkasan Proposal & PRD Lomba

Sistem Manajemen Stok Obat Offline-First Puskesmas 3T Indonesia

1. Problem Statement

Di daerah 3T (Kepulauan Mentawai, pedalaman Papua, Maluku), faskes primer menghadapi: sinyal 2G/tanpa internet berbulan-bulan, pasokan kapal berkala sebulan sekali, dan buku register kertas yang memicu stockout serta obat kadaluarsa tidak terdeteksi.

2. Arsitektur Unggulan

  • True Offline-First: Menggunakan embedded local storage (SQLite/IndexedDB) sebagai single source of truth.
  • Multi-Channel Sync: REST API WiFi/4G, SMS Gateway 2G base64 kompresi, dan Ekspor fisik SD Card.
  • Edge-AI RKO: Model prediktif tepi v2.4 berjalan lokal tanpa server cloud, memproyeksikan lonjakan musiman (ISPA/Diare).
  • UI Ergonomis Medis: Target sentuh besar 56dp+, kontras tinggi outdoor, palet Deep Green & Forest Green.

3. Key Performance Indicators (KPI)

Penurunan limbah obat kedaluwarsa ≥ 65% dalam 6 bulan; ketersediaan 20 jenis obat esensial > 95%; waktu pembuatan laporan RKO turun dari 5 hari kerja menjadi < 15 menit.
